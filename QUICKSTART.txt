================================================================
    HOW TO START THE SYSTEM
================================================================

STEP 1: Install Dependencies (Only needed once)
----------------------------------------
cd /Users/emilemajed/specksondecks
pip3 install -r requirements.txt


STEP 2: Start the Booking System
----------------------------------------
cd /Users/emilemajed/specksondecks
python3 app.py

Or simply run:
./START.sh


STEP 3: Access Your System
----------------------------------------
📋 BOOKING FORM (for clients):
   http://localhost:5000/book

📊 ADMIN DASHBOARD (for you):
   http://localhost:5000/dashboard


OPTIONAL: Start Automated Reminders
----------------------------------------
Open a NEW terminal window and run:
cd /Users/emilemajed/specksondecks
python3 reminder_system.py

This runs in the background and automatically sends:
- Follow-up emails to inquiries
- Event reminders (7 days & 1 day before)
- Payment reminders
